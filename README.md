# Loss Development Triangles & Reserve Forecasting

## Overview
This project uses Excel to analyze synthetic insurance claims data, construct paid loss development triangles, calculate age-to-age development factors and cumulative development factors (CDFs), and estimate ultimate paid claims and unpaid reserves using the Chain Ladder method.

## Objectives
- Build a paid loss development triangle by accident year and development age.
- Calculate age-to-age factors and cumulative development factors.
- Forecast ultimate paid claims and estimate unpaid reserves.
- Validate forecasts against actual ultimate claims using error metrics and visualizations.

## Tools
- Microsoft Excel
- Excel formulas, SUMIFS, XLOOKUP, and charts

## Key Outputs
- Paid loss development triangle
- Development factor and CDF calculations
- Accident-year ultimate paid claims and reserve estimates
- Forecast accuracy analysis using absolute error, percentage error, and forecast bias
- Actual versus estimated ultimate claims comparison chart

## Disclaimer
This project uses synthetic claims data for educational and portfolio purposes. Results are illustrative and do not represent actual insurance company reserves.
